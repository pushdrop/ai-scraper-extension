# Smart Copy Page

A blazing fast, AI-assisted Chrome Extension that lets you copy structured data (product grids, search results, directory listings) from any webpage without manually writing CSS selectors or building scrapers.

## How It Works

This extension leverages a hybrid architecture to maximize privacy, accuracy, and speed:
1. **Local Scanning**: The content script efficiently scans the webpage locally to identify repeated structural patterns (candidates).
2. **AI Inference**: A condensed structural skeleton is sent to an LLM (via OpenAI API) which infers the fields, labels them in human terms, and generates robust CSS selectors. The AI **does not** scrape the data itself.
3. **Local Extraction**: The extension runs the AI-generated CSS selectors locally in your browser to extract the data and format it into CSV, JSON, or Markdown.

Your full page HTML and actual row data never leave your browser. The AI only sees a tiny abstract skeleton of the DOM structure!

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pushdrop/ai-scraper-extension.git
   cd ai-scraper-extension
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the extension:
   ```bash
   npm run build
   ```

4. Load the extension in Chrome:
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable **Developer mode** (toggle in the top right).
   - Click **Load unpacked** and select the `dist` folder generated by the build step.

## Configuration

Before using the extension, you must configure your OpenAI API key:
1. Right-click the Smart Copy Page extension icon in your Chrome toolbar.
2. Select **Options**.
3. Enter your OpenAI API Key.
4. *(Optional)* Customize the default Model (defaults to `gpt-4o-mini`).
5. Click **Save Settings**.

## Usage

1. Navigate to any page containing a list, grid, or table of data (e.g., Amazon search results, real estate listings).
2. Click the Smart Copy Page extension icon.
3. Click **Copy Useful Data**.
4. The extension will automatically detect the best data group. If multiple plausible lists exist, it will present a human-readable chooser (complete with hover-highlights on the page).
5. Copy the extracted data directly to your clipboard in CSV, JSON, or Markdown formats!
